That PNG is a finished Minecraft skin. Upload it at minecraft.net → profile → skins, or in Bedrock: Dressing Room → Classic Skins → Owned → Import. Vanilla Java takes 64×64 only; 128 and 256 are for Bedrock skin packs and for Java with an HD-skin mod, so at those sizes there is a 64×64 on offer too.
